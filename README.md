# South Africa vs Australia — Cricket Match Post-Mortem Analysis

A three-page Power BI case study analysing a Test match through ball-by-ball data.

## Match summary

- **Fixture:** South Africa vs Australia
- **Format:** Test
- **Venue:** St George's Park, Gqeberha
- **Dates in the supplied dataset:** 18–22 October 2026
- **Result in the supplied dataset:** South Africa won by an innings and 31 runs
- **Innings:** South Africa 425/9 declared; Australia 99 all out; Australia 295 all out

## Dashboard highlights

- 819 total runs
- 29 dismissals recorded
- 96 boundaries (91 fours and 5 sixes)
- 73.26% dot-ball percentage
- Innings comparison and cumulative run progression
- Dot-ball percentage grouped into 20-over bands
- Batter summary and wicket-by-bowler comparison

## Tools and skills

Power BI Desktop, Power Query, DAX, data cleaning, calculated columns, measures, slicers, data visualization and exploratory analysis.

The included GitHub Actions workflow deploys the site on pushes to `main`. In **Settings → Pages**, choose **GitHub Actions** as the deployment source if it is not already selected.

## Scope and data notes

This repository contains screenshots and descriptive material only. The editable Power BI `.pbix` file and original ball-by-ball data are intentionally not included.

The match details and figures above are reproduced from the dataset and Power BI report supplied for this project. The player-level bowling visual is presented as the report currently displays it; dismissals are not automatically equivalent to wickets credited to the bowler. A bowler-credit calculation should filter dismissal types before being described as official bowling wickets.
